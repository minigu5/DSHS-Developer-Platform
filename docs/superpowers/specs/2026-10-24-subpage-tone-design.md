## 1. 의도

홈만 리뉴얼되어 홈에서 다른 페이지로 넘어가면 바탕색·머리 구성·버튼 모양·여백이 달라 다른 사이트처럼 느껴진다. 홈에서 정한 요소(흰 바탕, 가운데 정렬 세로 스택, IBM Plex Sans KR 제목, 알약 버튼, 22% 둥근 아이콘 스티커, 모눈 배경)를 하위 페이지에 일관되게 적용해 사이트 전체를 한 덩어리로 만든다.

## 4. 공통 규칙 (사용자 결정 사항)

### 4.1 바탕과 면

- 페이지 바탕: `bg-white dark:bg-zinc-950` (현재 하위 페이지의 `bg-zinc-50`을 전부 교체).
- 보조 구간(프로필의 "등록한 프로젝트" 등): `bg-zinc-50 dark:bg-zinc-900/40` + `border-t border-zinc-200 dark:border-zinc-800`. 홈 하단 띠와 같은 리듬.
- 카드: `rounded-3xl`(24px), `border-zinc-200 dark:border-zinc-800`, `bg-white dark:bg-zinc-900`, `shadow-sm`. hover는 `hover:border-zinc-300 dark:hover:border-zinc-700`(색만 바뀜).
- 작은 상자(입력, 선택 카드, 드롭존 등): 12~16px 모서리.

### 4.2 페이지 머리(PageHero)

홈 히어로의 축소판. 모든 목록·상세 진입 페이지·폼 페이지의 첫 요소.

- 구조(가운데 정렬 세로 스택): **섹션 색 아이콘 타일** → **h1(Plex)** → **한 줄 설명** → **알약 버튼(선택)** → **추가 요소(선택: 검색창, 세그먼트 등)**.
- 배경: 모눈(`.paper-grid`, §4.6 값) + 아래 `border-b border-zinc-200 dark:border-zinc-800`.
- 크기(기본형): 패딩 위 48 / 아래 40(모바일 32 / 28). 타일 44px, `rounded-xl`, 아이콘 22px. h1 `text-3xl sm:text-[40px]` 700, `font-heading`, `break-keep`. 설명 `text-base sm:text-[17px] text-zinc-600 dark:text-zinc-400 max-w-[36em]`.
- **모바일에서는 설명 문장을 숨긴다**(머리 높이 약 40px 절약). 데스크탑은 유지.
- 축소형(compact, 에디터·위저드 페이지용): 패딩 30 / 26(모바일 22 / 20), 타일 36px `rounded-[10px]` 아이콘 18px, h1 `text-2xl sm:text-[28px]`, 설명 없음.
- 로딩 시퀀스: 머리 요소만 `.rise`로 한 번 등장(타일 0ms, 제목 60ms, 설명 120ms, 버튼 180ms, 추가 요소 240ms). 홈의 `.rise` 키프레임을 재사용한다. **카드·목록은 애니메이션 없음**(스크롤 리빌은 홈 전용).
- 프로필 페이지는 타일 대신 아바타 스티커가 들어간 변형(§5.7).

### 4.3 섹션 색

PageNav와 같은 색을 페이지에도 쓴다.

| 섹션 | 색(진한, 흰 글자 가능) | 연한 배경 / 글자 | 다크 연한 배경 / 글자 |
|---|---|---|---|
| 탐색·프로젝트 상세·프로필·로그인 | blue-600 | blue-50 / blue-700 | blue-950 / blue-300 |
| 프로젝트 등록·수정 | emerald-700 | emerald-100 / emerald-700 | emerald-950 / emerald-300 |
| 가이드 | purple-600 | purple-100 / purple-700 | purple-950 / purple-300 |
| **개발 팁** | **pink-600** (`#db2777`) | pink-100 `#fce7f3` / pink-700 `#be185d` | `#500724` / pink-300 `#f9a8d4` |
| 해줘! | orange-700 | orange-100 / orange-700 | orange-950 / orange-300 |
| 공지사항 | sky-700 | sky-100 / sky-700 | sky-950 / sky-300 |

- 개발 팁은 amber → **pink로 교체**. amber를 팁 색으로 쓰던 곳 전부 바꾼다: `page-nav.tsx`(pillClass), 홈 `recent-posts.tsx`의 팁 타일/링크 색(117·124행 부근). `how-it-works.tsx`의 amber는 별점이므로 유지. 별점(`fill-amber-400`)과 공지 카테고리 "의견 수렴"(amber)은 팁 색이 아니므로 **유지**.
- **팁 색의 출처(설계자 결정)**: Tailwind v4의 `pink-600`은 oklch 기반이라 표의 hex(`#db2777`, 시안에서 승인된 색)보다 밝고 자홍빛이며 흰 글자 대비가 4.5:1 경계다. 따라서 팁 색만 `globals.css`의 `@theme`에 커스텀 토큰으로 정의해 쓴다: `--color-tip-600: #db2777`, `--color-tip-700: #be185d`, `--color-tip-100: #fce7f3`, `--color-tip-300: #f9a8d4`, `--color-tip-950: #500724` → `bg-tip-600`, `text-tip-700`, `bg-tip-100`, `dark:bg-tip-950`, `dark:text-tip-300`. 다른 다섯 섹션은 홈이 이미 쓰는 Tailwind v4 클래스(`blue-600` 등)를 그대로 쓴다(표의 hex는 참고값).
- 섹션 색을 쓰는 곳은 **세 군데만**: ① 머리 아이콘 타일(연한 배경 + 진한 글자), ② 페이지의 주 버튼(진한 색 + 흰 글자), ③ 활성 상태 칩(필터·세그먼트·내비). 나머지는 zinc.
- **예외 — 선택이 많은 폼**(프로젝트 등록·수정, 프로필 설정): 선택 상태를 섹션 색으로 칠하지 않는다. 선택 = 무채색 반전(§4.5). 섹션 색은 머리 타일과 제출 버튼에만.
- **위저드**(가이드, 해줘 등록)처럼 한 화면에서 하나만 고르는 곳은 섹션 색 선택 표시를 유지한다.

### 4.4 버튼·칩·입력

- 버튼은 모두 `rounded-full`. 주 버튼 h-11(44px) `px-5~6`, 보조 h-9(36px), 작은 것 h-7.5(30px). 아이콘 16px 왼쪽. `active:scale-[0.96] transition-[background-color,scale]`.
- 주 버튼 = 섹션 색 + 흰 글자. 보조 = `border-zinc-300 dark:border-zinc-700 bg-white dark:bg-zinc-900`. 셋째 = ghost(글자만).
- 칩: `rounded-full h-5 text-[11px]` 윤곽선(zinc-200). 종류 배지는 `rounded-md bg-blue-50 text-blue-700`(현재 ProjectCard 그대로).
- 입력: h-11(44px) `rounded-xl border-zinc-200 bg-white dark:bg-zinc-900`. 큰 제목 입력(에디터)은 테두리 없이 밑줄만, `font-heading text-[26px] font-bold`(모바일 22px).
- 텍스트영역·에디터 상자: `rounded-2xl`.

### 4.5 폼 선택 UI (무채색 반전)

등록·수정 폼의 선택 상태.

- 선택 카드(종류 등): 기본 `border-zinc-200 bg-white`; 선택 시 `border-zinc-900 bg-zinc-50 dark:border-white dark:bg-zinc-900`, 아이콘 타일 `bg-zinc-900 text-white dark:bg-white dark:text-zinc-950`.
- 토글 칩(플랫폼·카테고리·라이선스): 기본 윤곽선; 선택 시 `bg-zinc-900 text-white border-zinc-900 dark:bg-white dark:text-zinc-950`. 잠긴 선택(웹사이트 선택 시 전체 플랫폼)은 선택 스타일 + `opacity-35`, `tabIndex={-1}`, `aria-disabled`.
- 라디오 카드(공개/비공개, 개인/팀, 오픈/비공개 소스): 가이드 위저드 옵션 행과 같은 모양(아이콘 타일 + 라벨/설명 + 오른쪽 원). 선택 시 테두리·원이 zinc-900(다크 흰색).

### 4.6 모눈 배경

- 라인 색을 연하게: 라이트 `#f0f0f3`(현재 `#ececef`), 다크 `#18181c`(현재 `#1c1c20`). `globals.css`의 `.paper-grid`·`.dark .paper-grid` 값만 바꾼다. 홈 히어로도 이 값을 따른다.
- 쓰는 곳: 홈 히어로, 모든 PageHero, 로그인·온보딩·접근 거부 전체 바탕. 그 외에는 쓰지 않는다.
- **모눈 물결(사용자 결정 2026-10-24, 모든 모눈에 적용 — 홈 히어로 포함)**: 모눈 전체가 균일하게 움직이는 대신 "바다 표면처럼 일부는 또렷하고 일부는 흐린" 움직임.
  - 구현: 모눈을 요소의 `::before` 레이어(절대 위치, `inset-0`, `z-index:0`, `pointer-events:none`)에 그리고, 내용은 그 위(`relative z-10`). 홈의 `.paper-grid`도 같은 방식으로 바꾼다(요소 배경 → `::before`).
  - 흐름: `background-position`을 **10초**에 대각선 24px(한 칸) `linear infinite`. 한 칸 뒤 같은 자리라 끊김 없음.
  - 물결: `mask-image`(+`-webkit-mask-image`) 3층 — ① `radial-gradient(closest-side, #000 0%, #000 30%, transparent 100%)` 크기 `75% 160%`, ② 같은 꼴 크기 `60% 130%`(#000 25%까지), ③ `linear-gradient(rgba(0,0,0,.38), rgba(0,0,0,.38))` 전체. `mask-repeat: no-repeat`. 즉 바탕은 모눈이 38%만 보이고 두 덩이 안에서는 100%.
  - 덩이 이동: `mask-position`을 28초 `ease-in-out infinite alternate`로 `-15% 45%, 115% 55%` → `55% 85%, 35% 5%` → `115% 25%, -15% 75%`(세 번째 층은 `0 0` 고정). 두 덩이가 서로 반대 방향·다른 속도로 지나간다.
  - `prefers-reduced-motion: reduce`면 두 애니메이션 모두 정지(마스크는 첫 위치에 고정, 모눈은 보임).
  - 색 블롭·블러가 아니라 모눈의 가시도만 바뀌는 것이므로 CLAUDE.md의 "블러 블롭 금지"와 충돌하지 않는다. 다른 장식을 추가하지 않는다.
  - 공용 CSS 클래스 하나(`.paper-grid`를 확장)로 두고 홈·PageHero·독립 화면이 모두 같은 클래스를 쓴다. 이 변경은 홈 파일 중 `globals.css`와 히어로 `<section>`의 구조(내용 래퍼에 `relative z-10` 추가)에만 닿는다 — §2의 홈 수정 허용 목록에 ④로 추가.

### 4.7 여백·너비

- 페이지 좌우 여백: **모든 폭에서 24px**(`px-6`). 현재 `px-4 sm:px-6`은 하위 페이지 전부 `px-6`으로. `SiteHeader` 컨테이너도 동일.
- 콘텐츠 너비: 목록·상세 `max-w-5xl`(1024), **탐색만 `max-w-6xl`**(사이드바 때문, 유지), 글(팁·해줘 상세, 에디터) `max-w-3xl`(768). 폼(프로젝트 등록·수정)은 본문 `max-w-3xl` + 데스크탑 오른쪽 레일 200px을 `max-w-5xl` 안에.
- 카드 그리드 간격 `gap-5`(모바일 `gap-4`).

### 4.8 프로젝트 아이콘 = 스티커

- 어디서나 `rounded-[22%]`. 상세 페이지 112px(모바일 72px), 등록 폼 미리보기 72px, 카드 48px, 홈 나열 72/80px.
- 상세·등록 폼·프로필 아바타에는 홈 나열과 같은 스티커 처리: `ring-[3px] ring-white dark:ring-zinc-950 shadow-[0_8px_20px_-8px_rgba(0,0,0,0.25)]`.

### 4.9 다크 모드 긴 글

- 팁 상세·해줘 상세·프로젝트 상세의 마크다운 본문은 카드(`rounded-3xl border bg-white dark:bg-zinc-900`) 안에 둔다. 다크에서 바탕(zinc-950)보다 한 단계 밝은 면 위에 글이 올라간다.
- 본문 글자색: 라이트 `text-zinc-700`, 다크 `text-zinc-300`(현재 `Markdown` 컴포넌트가 쓰는 색이 더 어두우면 올린다).

### 4.10 사이트 로고

- `public/logo.svg`(검정 둥근 사각형 + `</>`)를 헤더(이미 사용 중), 로그인(큰 크기), 그리고 하위 페이지에 푸터를 둔다면 푸터에도 쓴다. 다크에서는 1px `border-zinc-800`로 윤곽 유지(현재 헤더 방식).

## 5. 페이지별 설계

각 항목은 "현재 → 바뀌는 것"만 적는다. 적지 않은 것은 현재 그대로.

### 5.1 탐색 `/explore` (blue)

- PageHero: 타일 `Search`, 제목 "모든 프로젝트", 설명 "친구들이 만든 프로젝트를 찾아보고, 써 본 뒤 리뷰를 남겨요.", 추가 요소로 **큰 검색창**(h-13(52px, 모바일 46px) `rounded-full`, 최대 640px, 돋보기 아이콘, placeholder "프로젝트, 태그, 만든 사람 검색"). 검색창이 이 페이지의 히어로다.
- **데스크탑: 사이드바 유지.** 머리 아래 `max-w-6xl` 컨테이너에 `aside`(224px, 접이식 3그룹: 프로그램 종류·카테고리·플랫폼, 아이콘+라벨 토글, 활성은 `bg-blue-500/12 text-blue-700`) + 본문. 사이드바 상단의 검색 입력은 제거(머리로 올라감). `sticky top-24 self-start` 유지.
- **모바일: 사이드바 대신 고정 칩 바.** 머리 바로 아래 `sticky top-0`(헤더 아래) 가로 스크롤 바: [종류 ▾][카테고리 ▾][플랫폼 ▾] 드롭다운 알약 + 선택된 값은 blue 연한 배경 칩(× 포함) + 오른쪽 정렬 알약. 드롭다운은 현재 모바일 필터처럼 `absolute top-full` 패널로 열린다(레이아웃 밀림 없음).
- 본문: 상단에 결과 수("24개 중 웹사이트 11개", `tabular-nums`) + 정렬 알약(현재 정렬 기능 그대로). **카드 그리드 최대 2열**(`grid-cols-1 lg:grid-cols-2`). 카드는 기존 `ProjectCard` 그대로.
- 바탕 흰색.

### 5.2 프로젝트 상세 `/projects/[id]` (blue)

- 머리는 PageHero가 아니라 **상세 머리**: 위에 "← 모든 프로젝트" 작은 링크. 왼쪽 아이콘 스티커 112px(모바일 72px), 오른쪽에 종류 배지 + 태그 칩 → h1(Plex, `text-[26px] sm:text-[38px]`) → 한 줄 설명(`text-[15px] sm:text-[17px]`) → 작성자 줄(아바타 28px + 이름 + "· 개인 프로젝트 · 2026년 9월 12일 등록"; 팀이면 "· 팀 프로젝트") → 버튼 행: [웹사이트 방문](blue, 외부 링크) [GitHub 저장소](보조) [수정하기](ghost, 권한자만).
- **수치 띠(stat strip)**: `rounded-3xl border bg-white shadow-sm`, 4칸을 `grid-cols-2 sm:grid-cols-4`로 나눠 칸 사이 `border-zinc-100` 선. 칸 = 작은 라벨(11px zinc-500) / 큰 값(18px 600 `tabular-nums`) / 보조(11px zinc-500).
  1. 별점: ★ 4.6 / "리뷰 12개" (리뷰 없으면 "–" / "아직 리뷰가 없어요")
  2. 방문: 1,284 / "회" (`url` 없으면 칸 숨기고 3칸)
  3. 플랫폼: 웹사이트+전체면 "Web" / "모든 브라우저", 아니면 첫 플랫폼 라벨 / "외 N개"
  4. 소스코드: "오픈소스" 또는 "비공개" / 라이선스 요약(허용 항목 수 "허용 4개")
- 본문 2열(`md:grid-cols-3`, 본문 2 + 사이드 1): 본문 "프로젝트 상세" 카드(마크다운, §4.9), 사이드 카드 3개 — **개발자**(아바타 36 + 이름 + 이메일 + "프로필 보기 ›"; 팀이면 팀 이름 + 팀원 목록), **라이선스**(허용됨 / 제한·조건, 현재 아이콘·점 목록 그대로), **정보**(종류·플랫폼·공개 여부·등록일·최근 수정 key-value). 현재 "환경 및 플랫폼" 카드는 정보 카드에 합친다.
- 리뷰: "리뷰 12" 제목(Plex) → 작성 폼 카드(별점 선택을 폼 머리 오른쪽에, 본문 `rounded-2xl`, 버튼 "리뷰 남기기" blue) → 리뷰 카드 목록(아바타·이름·시간·별점·본문). 별점 없는 리뷰는 별 행 생략.

### 5.3 개발 팁 목록 `/tips` (pink)

- PageHero: 타일 `Newspaper`, "개발 팁", 설명 그대로, 버튼 [팁 작성](pink) [해줘! 둘러보기](보조, orange 윤곽·글자 — 현재 버튼 유지).
- 목록 위 한 줄: "38개의 팁"(왼쪽). 정렬 토글은 **넣지 않는다**(비목표).
- 카드(`TipCard`): 커버 비율 16:10, 카드 하단 정보 줄(작성자 / ♥ 수 · 댓글 수 · 상대시간)을 `border-t border-zinc-100` 위에. 그 외 현재 유지. 3열 유지.

### 5.4 팁 상세 `/tips/[id]` (pink) · 해줘 상세 `/haejwo/[id]` (orange) · 공지 상세 `/announcements/[id]` (sky)

세 상세는 같은 **글 레이아웃**.

- `max-w-3xl`. 첫 줄: "← 개발 팁"(목록 링크) 왼쪽, 오른쪽에 [수정](보조 xs) [삭제](ghost xs) — 권한자만.
- 태그/카테고리 칩 → h1(Plex `text-3xl sm:text-4xl`) → (팁만) 한 줄 요약 → 작성자 줄(아바타 36 + 이름 + · 날짜). 작성자 영역은 프로필 링크(현재와 동일).
- (팁만) 커버 16:9 `rounded-3xl border`.
- **본문 카드**(§4.9): `rounded-3xl border bg-white dark:bg-zinc-900 p-6 sm:p-9`. 팁은 카드 하단에 `border-t border-zinc-100` 위 좋아요 알약(♥ 24, 현재 낙관적 토글) + "도움이 됐다면 눌러 주세요".
- 팁: 아래 댓글 섹션(제목 "댓글 6" Plex, 댓글 행, 입력 상자). 현재 `TipComments` 로직 그대로.
- 해줘: 본문 카드 아래 상태별로 하나 —
  - 미완료 + 로그인: **점선 카드**(`border-dashed rounded-[20px]`) "이 아이디어, 만들었어요?" + 설명 한 줄 + [구현완료로 표시](orange, 현재 다이얼로그 로직).
  - 완료: **연결 프로젝트 카드**(emerald 연한 테두리·배경, 아이콘 44 + "구현된 프로젝트" 라벨 + 제목 + 설명, 프로젝트 링크).
- 공지: 고정 공지면 제목 위 칩 줄에 핀 아이콘 + "고정". 관리자 고정 토글 버튼은 수정/삭제 옆.

### 5.5 팁 작성 `/tips/new`·`/tips/[id]/edit` (pink) · 공지 작성 `/announcements/new`·`/[id]/edit` (sky)

- PageHero **compact**: 타일 + 제목("새 팁 작성" / "팁 수정" / "공지 작성").
- `max-w-3xl`. 카드 1(메타): **큰 밑줄 제목 입력**(§4.4) → 2열(한 줄 요약(필수, 최대 30자 힌트) / 태그(쉼표 구분 힌트)) → 대표 이미지: 점선 드롭존(`border-2 border-dashed rounded-2xl`, 아이콘 + "이미지를 끌어다 놓거나 눌러서 골라요" + "PNG·JPG·WebP, 10MB까지") + 아래 URL 입력 폴백. 현재 `ImageUploadInput` 로직 그대로, 겉모양만.
- 카드 2(본문): 머리에 "본문 (마크다운)" + 오른쪽 탭(작성 / 분할(데스크탑만) / 미리보기, `rounded-[10px] bg-zinc-100` 세그먼트형). 에디터 상자 `rounded-2xl` 최소 높이 320px, 모노스페이스 13px, Tab 들여쓰기 유지.
- 하단 행: 왼쪽 안내("발행하면 바로 목록에 올라가요. 수정은 나중에도 할 수 있어요.") 오른쪽 [취소](ghost) [팁 발행](pink) — 수정 모드는 "저장".
- 공지 작성: 카드 1 맨 위에 **카테고리 카드 선택 한 줄**(현재 카드 선택 UI, 선택 상태는 sky — 위저드형 단일 선택이므로 섹션 색 허용). 요약·태그·이미지 없음(현재 공지는 제목·카테고리·본문만).

### 5.6 해줘 목록 `/haejwo` (orange) · 해줘 등록 `/haejwo/new` (orange) · 공지 목록 `/announcements` (sky)

- 해줘 목록 PageHero: 타일 `Megaphone`, "해줘!", 설명, 버튼 [해줘! 등록](orange), 추가 요소로 **상태 세그먼트**(`rounded-full bg-zinc-100 p-[3px]` 안에 알약 **3개**: 전체 12 · 구현 요청 중 10 · 완료 2; 활성은 흰 배경 + 숫자 orange). `in_progress` 상태는 설정하는 UI·서버 액션이 없어 항상 0이므로 세그먼트에 넣지 않는다(설계자 결정). DB·카드의 "개발 중" 라벨 처리는 그대로 둔다. 클라이언트 필터(쿼리스트링 `?status=` 반영은 선택).
- 해줘 수정 `/haejwo/[id]/edit`(`HaejwoWizard mode="edit"`): PageHero compact 제목 "해줘! 수정", 단계 알약·"이전" 버튼 없이 3단계 작성 화면만. 버튼 "저장". (설계자 결정)
- 해줘 카드: 상태 알약(현재 색) + 종류 칩(아이콘 포함) + 카테고리 칩 → 제목 2줄 → 하단 작성자·시간. **완료 카드는 `border-dashed`** + "✓ 연결된 프로젝트: 이름" 한 줄(emerald 글자). 3열 유지.
- 해줘 등록 위저드: PageHero compact("해줘! 등록") + 가이드 위저드와 같은 틀(`max-w-2xl`: 위 행 [← 이전] ghost + "N단계" orange 연한 알약, h2 질문 Plex `text-2xl sm:text-[28px]`, 부제). 1·2단계 선택 카드는 가이드 옵션 행 모양(아이콘 타일 orange). 3단계: 부제에 "앱 · 유틸리티로 분류했어요." 식으로 앞 선택 요약, 큰 밑줄 제목 입력, 탭(작성/미리보기) + 에디터, [해줘! 등록](orange).
- 공지 목록 PageHero: 타일 `Bell`, "공지사항", 설명, [공지 작성](sky). 카드: 카테고리 알약(티커와 같은 색 — promotion blue, beta violet, feedback amber, update emerald, general zinc, admin rose) + 고정이면 오른쪽 끝 핀 아이콘 "고정"(sky 글자), 제목 2줄, **본문 첫 문단 2줄 요약**(마크다운 기호 제거한 평문), 하단 작성자·시간. **고정 공지는 테두리 sky-300/sky-800**(배경 칠하지 않음). 3열 유지.

### 5.7 가이드 위저드 `/guide` (purple)

- 아래 위저드 `max-w-2xl`: 위 행 [← 이전](첫 단계 숨김) + "N단계" purple 연한 알약(현재 회색 글자 → 알약). h2 Plex. 옵션 행: 아이콘 타일 **purple-100/purple-700**(현재 blue-50 → 섹션 색), 선택 시 `border-purple-600 bg-purple-50/60` + 오른쪽 체크 원 purple. 비활성 옵션은 현재대로 zinc + 이유 표시.

### 5.8 개발자 프로필 `/developers/[id]` · 마이페이지 `/me` (blue)

- `/me`는 현재처럼 본인 프로필로 리다이렉트. 본인이면 관리 요소가 붙는다.
- PageHero 변형: 아바타 스티커 104px(모바일 84px, `ring-[3px]` + 그림자) → **닉네임만** h1(Plex `text-[26px] sm:text-[32px]`; 닉네임 없으면 실명) → 자기소개(`max-w-[34em]`) → **연락처 알약**(아이콘 + 값, `h-[34px] rounded-full border`; GitHub·인스타·이메일·웹사이트 등 `contacts` 순서대로. 이메일은 항상 알약 하나로 포함) → 관심분야 칩. **실명·이메일 줄은 머리에 표시하지 않는다**(이메일은 알약에만).
- 본인이면 알약 아래 [프로필 설정](보조 sm, 현재 다이얼로그) [로그아웃](ghost sm).
- 아래 **zinc-50 띠**: "등록한 프로젝트 N"(Plex, 숫자는 zinc-500) + 2열 `ProjectCard`. 본인이면 카드 푸터 오른쪽에 공개/비공개 알약 + [수정](xs) (현재 `manage` 모드 정보), 마지막 칸에 점선 "+ 새 프로젝트 등록" 카드. 남이면 showcase 모드.
- 그 아래 흰 구간: "작성한 글 N" — 팁과 해줘를 한 목록에 얇은 행(`rounded-2xl border`, 커버 썸네일 56×40 또는 orange 연한 칸, 제목, "개발 팁 · 3일 전" / "해줘! · 3주 전 · 완료", 오른쪽 ♥·댓글 또는 상태 알약). 글이 없으면 "아직 쓴 글이 없어요" + 작성 링크.
- 현재의 왼쪽 고정 프로필 카드는 제거.

### 5.9 프로젝트 등록 `/projects/new` · 수정 `/projects/[id]/edit` (emerald)

- PageHero 기본형: 타일 `Rocket`, "프로젝트 등록하기" / "프로젝트 수정", 설명.
- 아래 `max-w-5xl` 안에 본문(`max-w-3xl`) + 데스크탑 오른쪽 **목차 레일**(200px, `lg:` 이상에서만): 카드 5개 이름 + 완료 원(필수 항목이 다 채워지면 zinc-900 체크), 아래 "필수 항목 4 / 7". 클릭 시 해당 카드로 스크롤(`scrollIntoView`), 현재 보이는 카드는 `bg-zinc-100` 강조(IntersectionObserver).
- 폼을 **카드 5장**으로 나눈다(각 카드 `rounded-3xl border p-6 sm:p-7`, 제목 Plex 18px):
  1. **기본 정보**: 아이콘(72px 스티커 미리보기 + 칩 2개 "URL에서 자동 추출"/"직접 올리기" + 힌트) → 2열(프로젝트 이름 / 웹사이트 또는 다운로드 링크) → 간단 설명(힌트 "탐색 카드에 2줄까지 보여요. 60자 안쪽이 좋아요.")
  2. **상세 설명 (마크다운)**: 탭(작성/분할/미리보기) + "Tab 키로 들여쓰기" 힌트 + 에디터.
  3. **분류**: 프로그램 종류 = 선택 카드 그리드(3열, 모바일 2열; 아이콘 타일 + 라벨 + 한 줄 설명), 지원 플랫폼 = 토글 칩(웹사이트면 전부 선택·잠금 + 안내문 유지), 카테고리 = 토글 칩(아이콘 포함) + "기타" 직접 입력.
  4. **소스코드·라이선스**: 소스코드 공개 = 라디오 카드 2개(오픈소스 / 비공개), 오픈이면 저장소 링크 입력(필수), 허용하는 것 = 토글 칩 6개 + 힌트("체크하지 않은 항목은 상세 페이지에 '제한'으로 표시돼요.") + 기타 조건 입력.
  5. **공개 범위·만든 사람**: 공개 여부 = 라디오 카드(공개 / 비공개), 비공개면 허용 이메일 입력 목록; 만든 사람 = 라디오 카드(개인 / 팀), 팀이면 팀 이름 + 팀원 추가(현재 아바타 카드 목록 유지).
  6. (수정 페이지, `canDelete`일 때만) **위험 구역**: rose 테두리, 제목 rose, 왼쪽 경고문 + 오른쪽 [프로젝트 삭제](보조 sm, 빨간 채움 아님). 현재 Dialog 확인 흐름 유지.
- 모든 선택 상태는 §4.5 무채색 반전. emerald는 머리 타일과 마지막 [등록하기]/[저장하기](주 버튼)에만. 하단 행: [취소](ghost) [등록하기](emerald, `Rocket` 아이콘).

### 5.10 로그인 `/login` (blue, 헤더 없음)
