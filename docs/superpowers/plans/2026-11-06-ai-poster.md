# AI 포스터 만들기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 프로젝트 상세에서 관리자가 AI로 A4 홍보 포스터를 만들고(그림 = Workers AI, 글·배치 HTML = Gemini), 대화로 고치고, 띠·QR이 붙은 PNG·PDF로 받는다.

**Architecture:** Gemini가 `<img src="ART">` 자리를 둔 HTML과 그림 주문(json)을 주면, 서버가 주문 비율대로 Workers AI(`AI` 바인딩)에 그림을 요청해 Cloudinary에 올리고, 정리한 HTML·그림 URL을 `project_posters`(서비스 키 전용)에 저장한다. 미리보기는 `sandbox` iframe(srcdoc) + iframe 밖 우리 띠, 내보내기는 Cloudflare Browser Rendering REST. 횟수는 DB 함수로 예약·환불.

**Tech Stack:** Next.js 16 App Router, Supabase(PostgreSQL), Gemini REST(`generateContent`), Workers AI 바인딩, Cloudinary, Cloudflare Browser Rendering REST, `qrcode` 1.5.4, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-05-ai-poster-design.md` (2026-11-06 개정 포함 — §5-1, §10-2, §11-0 필독)

## Global Constraints

- 1단계는 **관리자(`isDeveloper`)만**: 버튼·페이지·API 모두 `posterAllowed(isAdmin)` 검사. 플래그 `POSTER_OPEN_TO_ALL = false`. 처리방침은 고치지 않는다.
- **공개 프로젝트만**(`visibility = 'public'`). 비공개로 바뀐 프로젝트의 포스터는 지우지 않고 목록·편집·API에서 404/403.
- 캔버스: AI 영역 **1240×1518**, 띠 **1240×236**, 합계 1240×1754. 띠는 iframe 밖 우리 요소.
- AI HTML은 사이트 DOM에 넣지 않는다 — `<iframe sandbox="" srcdoc>`만, `allow-same-origin`·`allow-scripts` 금지.
- 저장 HTML엔 늘 `ART` 표시만, 그림 URL은 `art_url` 칸. Gemini에 data URI를 보내지 않는다.
- 그림은 **처음 만들 때·Gemini가 새 주문을 줄 때·"그림 다시 그리기" 버튼**에서만 그린다. HTML에 `ART` 자리가 없으면 그리지 않는다.
- 제한: 프로젝트당 3개, 글 요청 사람당 20/일(KST 자정), 그림 사람당 5/일·사이트 전체 `artSitePerDay`/일(UTC 자정 = KST 09:00, Cloudflare 할당량과 같은 시계). 429·503·시간 초과·차단·HTML 없음 → 환불.
- Workers 무료 CPU 10ms: Gemini는 스트림 조각 파싱 대신 한 번에 받기, 그림 base64는 디코딩하지 않고 data URI 그대로 Cloudinary로.
- 기존 규칙: 링크는 `@/components/shared/link`, 버튼 `rounded-full`, `transition-all` 금지, 해요체, 로딩 문구 `…`, 모바일 `px-6`, route group으로 `loading.tsx` 분리, 새 DB 함수는 `SET search_path = ''`·외래 키 인덱스, 쿠키 인증 상태 변경 Route Handler는 `isSameOrigin()`.
- migration은 `supabase db push`로 직접 적용. main 푸시 = migration 자동 적용이므로 **migration 커밋을 코드보다 먼저** 푸시.

## Review Focus

1. **Gemini가 HTML만 주고 json이 없거나, `ART` 자리 없이 주문만 준 응답** — 그림 횟수를 쓰지 않고, 기존 그림을 유지(첫 생성이면 회색 자리)해야 한다. → Task 4 `planArtAction` 테스트.
2. **그림 할당량이 대화 도중 바닥남** — 글 수정은 저장되고, 기존 그림 유지, 안내 "오전 9시에 다시 채워져요". → Task 4 `classifyArtError` + `planArtAction` 테스트, Task 5 수동 확인.
3. **AI HTML에 `<script>`·`on*=`·외부 CSS·`<base>`·`<meta refresh>`·`javascript:`** — 저장 전에 걷히고, srcdoc CSP가 남은 것도 막는다. → Task 2 `sanitizePosterHtml` 테스트.
4. **포스터를 만든 뒤 프로젝트가 비공개가 되거나 팀원에서 빠짐** — 목록·편집 404, API 403. → Task 4 `decidePosterAccess` 테스트.
