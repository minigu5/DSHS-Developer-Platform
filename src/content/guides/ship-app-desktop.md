## GitHub Releases에 설치 파일 올리기

GitHub Releases는 저장소에 설치 파일을 붙여 두는 곳이에요. 링크 하나만 보내면 친구가 받아서 설치해요. 무료예요.

[github.com/signup](https://github.com/signup)에서 가입해요. 가입했으면 에이전트에게 맡겨요.

> [!only platform=mac]
> > [!say]
> > 이 앱을 내 GitHub 계정에 공개 저장소로 올려 줘. 그리고 다른 Mac에서도 열리게 릴리스용으로 빌드해서, .app을 zip으로 묶어 GitHub Releases에 첫 버전으로 올려 줘. Apple 칩 Mac과 Intel Mac 둘 다에서 열리게 해 줘. 로그인이 필요하면 내가 할 수 있게 알려 줘.

> [!only platform=windows]
> > [!say]
> > 이 앱을 내 GitHub 계정에 공개 저장소로 올려 줘. 그리고 다른 Windows 컴퓨터에서도 열리게 릴리스용으로 빌드해서, 실행 파일을 zip으로 묶어 GitHub Releases에 첫 버전으로 올려 줘. 로그인이 필요하면 내가 할 수 있게 알려 줘.

중간에 브라우저가 열리면서 GitHub 로그인이나 승인을 물어보면, 그건 내가 눌러 줘요.

> [!ok]
> 저장소 페이지 오른쪽의 Releases에 첫 버전이 있고, 그 안에 zip 파일이 보여요. 이 페이지 주소를 친구에게 보내면 돼요.

## 경고 넘기는 법을 README에 쓰기

돈을 내고 서명하지 않은 앱이라, 친구가 처음 열면 컴퓨터가 막아요. 고장 난 게 아니에요. 넘기는 법을 저장소 첫 화면(README)에 적어 두면 친구가 혼자 해결해요.

> [!only platform=mac]
> 친구가 할 일: 앱을 한 번 열어 보고 막히면 **시스템 설정 › 개인정보 보호 및 보안**으로 가서 보안 항목의 **그래도 열기**를 누르고 Mac 암호를 넣어요. 이 버튼은 앱을 열려고 한 뒤 1시간쯤만 보여요.
>
> > [!say]
> > README.md에 이 앱 소개, 다운로드 방법(Releases에서 zip 받아 풀고 응용 프로그램 폴더로 옮기기), 그리고 처음 열 때 막히면 시스템 설정 › 개인정보 보호 및 보안에서 "그래도 열기"를 누르라는 안내를 한국어로 써서 GitHub에 올려 줘.

> [!only platform=windows]
> 친구가 할 일: "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보**를 누르고 **실행**을 눌러요.
>
> > [!say]
> > README.md에 이 앱 소개, 다운로드 방법(Releases에서 zip 받아 풀고 실행 파일 열기), 그리고 "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누르고 "실행"을 누르라는 안내를 한국어로 써서 GitHub에 올려 줘.

> [!ok]
> 저장소 첫 화면 아래에 설치 안내가 보이고, 친구가 그대로 따라 해서 앱을 열어요.

> [!more] 새 버전을 내려면
> 고친 뒤 에이전트에게 "새 버전으로 빌드해서 GitHub Releases에 올려 줘"라고 하면 돼요. 친구에게는 같은 Releases 주소를 다시 보내요.
