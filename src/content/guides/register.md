## 친구들한테 보여 주기

이 사이트는 대구과학고 학생들이 만든 프로그램을 모아 두는 곳이에요. 여기에 프로젝트를 등록하면 친구들이 둘러보다가 찾아서 써 보고, 별점과 리뷰를 남겨요. 뭐가 불편한지, 다음에 뭘 넣으면 좋을지 듣게 돼요.

아래 "내 프로젝트 등록하기"를 눌러 학교 계정으로 로그인하고 채워요.

- **주소**: 3장에서 만든 주소(사이트 주소, 스토어 페이지, GitHub 주소)를 넣어요. 아이콘은 주소만 넣으면 자동으로 가져와요.
- **설명**: 뭘 하는 프로그램인지, 어떻게 쓰는지 적어요. 에이전트에게 "이 프로젝트 소개 글을 친구들이 읽기 쉽게 써 줘"라고 맡겨도 돼요.
- **공개 여부**: 모두가 보게 하려면 공개로 둬요.

해줘!에서 본 아이디어로 만들었다면, 그 해줘! 글 아래의 **구현완료**를 누르고 방금 등록한 프로젝트를 골라요. 아이디어를 올린 친구가 바로 써 볼 수 있어요.

> [!ok]
> 모든 프로젝트 목록에 내 프로젝트 카드가 보여요.

> [!only type=website]
> **짧은 주소도 받아 보세요.** 등록한 웹사이트에는 `내이름.dshs.dev` 같은 주소를 붙일 수 있어요(한 사람당 3개). [도메인 마련하기](/domains) 화면에서 내 프로젝트 줄의 **도메인 마련하기**를 누르고 이름 → 확인 코드 → 올린 곳(Vercel·Netlify·Cloudflare Pages·GitHub Pages·GitLab Pages·Render·Railway) 순서로 따라가요. 확인 코드를 넣기 전에는 주소가 내 사이트로 열리지 않아요. 확인 코드는 에이전트에게 "이 줄을 사이트 head에 넣고 다시 배포해 줘"라고 맡기면 돼요. 도메인 마련하기 화면에 "연결됨"이 보이면 끝이에요.
