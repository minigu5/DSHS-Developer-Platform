## GitHub에 코드 올리기

GitHub는 코드를 인터넷에 보관하는 곳이에요. 다음 단계의 Vercel이 여기서 코드를 가져가서 사이트로 만들어요.

[github.com/signup](https://github.com/signup)에서 가입해요. 아이디는 사이트 주소에도 보일 수 있으니 알아보기 쉬운 걸로 정해요. 가입했으면 에이전트에게 맡겨요.

> [!say]
> 이 프로젝트를 내 GitHub 계정에 새 저장소로 올려 줘. 로그인이 필요하면 내가 할 수 있게 알려 줘.

중간에 브라우저가 열리면서 GitHub 로그인이나 승인을 물어보면, 그건 내가 눌러 줘요. 명령어는 에이전트가 쳐요.

> [!ok]
> `github.com/내아이디/저장소이름`에 들어가면 내 폴더의 파일 목록이 보여요.

> [!route] GitHub

## Vercel로 인터넷에 띄우기

Vercel은 GitHub에 있는 코드를 받아서 누구나 들어올 수 있는 사이트로 만들어 줘요. 개인 프로젝트는 무료예요.

1. [vercel.com/signup](https://vercel.com/signup)에서 **GitHub로 가입**해요. 요금제는 개인용(Hobby)을 골라요.
2. 대시보드 오른쪽 위의 **New Project**를 눌러요.
3. 목록에서 방금 올린 저장소를 골라요. 안 보이면 GitHub 저장소에 접근해도 되는지 묻는 창에서 허용해요.
4. 설정은 그대로 두고 **Deploy**를 눌러요.

1~2분 기다리면 끝나요. 앞으로 에이전트에게 고쳐 달라고 한 뒤 GitHub에 다시 올려 달라고 하면, Vercel이 알아서 사이트를 새로 만들어요.

> [!ok]
> `○○.vercel.app` 주소가 생기고, 휴대폰으로 열어도 내 사이트가 떠요. 이 주소를 친구에게 보내면 돼요.

> [!warn] 빌드가 실패하면
> 빨간 오류 화면이 나오면 오류 내용을 통째로 복사해서 에이전트에게 붙여 넣고 "Vercel에서 이렇게 실패했어, 고쳐서 다시 올려 줘"라고 해요.

> [!only data=unsure]
> > [!more] 로그인이 필요해졌다면
> > 만들다 보니 로그인하거나 글을 저장해야 하는 기능이 생겼다면 데이터베이스를 붙여야 해요. [로그인·저장 있는 가이드](guide:data=yes)로 가서 3장을 따라 해요.

> [!route] Vercel
