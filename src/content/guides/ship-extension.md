## 친구에게 zip으로 보내기

스토어에 올리기 전에 친구한테 먼저 써 보게 할 수 있어요. 돈도 심사도 필요 없어요. 에이전트에게 묶어 달라고 해요.

> [!say]
> 이 확장프로그램을 친구에게 보낼 수 있게 필요한 파일만 zip으로 묶어 줘. manifest.json이 zip을 풀었을 때 맨 위에 오게 해 줘. 다 만들면 zip 파일이 어디 있는지 알려 줘.

zip 파일을 메신저나 Google Drive로 친구에게 보내고, 친구는 이렇게 설치해요.

1. zip을 풀어서 폴더를 아무 데나 둬요. 설치한 뒤에도 이 폴더를 지우면 안 돼요.
2. Chrome 주소창에 `chrome://extensions`를 입력해요.
3. 오른쪽 위의 **Developer mode**(개발자 모드)를 켜요.
4. **Load unpacked**(압축해제된 확장 프로그램을 로드합니다)를 누르고 푼 폴더를 골라요.

> [!ok]
> 친구 Chrome의 확장 프로그램 목록에 내 확장프로그램이 생기고, 퍼즐 모양 아이콘을 누르면 보여요.

## Chrome 웹 스토어 개발자 등록

아무나 설치 버튼 하나로 받게 하려면 Chrome 웹 스토어에 올려요. 먼저 개발자로 등록해요.

1. [Chrome 웹 스토어 개발자 대시보드](https://chrome.google.com/webstore/devconsole)에 Google 계정으로 들어가요.
2. 개발자 약관에 동의하고 등록비를 내요. 한 번만 내는 돈(5달러)이고 카드 결제라 보호자와 같이 하는 게 좋아요.
3. 개발자 이메일을 적어요.

> [!warn]
> 개발자 이메일은 나중에 못 바꿔요. 계속 쓸 계정으로 정해요.

> [!ok]
> 대시보드에 **Add new item** 버튼이 보여요.

> [!route] Chrome 웹 스토어

> [!next] 등록했어요, 다음

## zip 올리고 심사 받기

친구에게 보낸 그 zip을 그대로 올리면 돼요. 스토어에 보일 설명은 에이전트에게 쓰게 해요.

> [!say]
> Chrome 웹 스토어에 올리려고 해. 스토어 소개 글, 그리고 이 확장프로그램이 쓰는 권한마다 왜 필요한지 설명하는 글을 한국어로 써 줘.

1. **Add new item**을 누르고 zip 파일을 올려요.
2. **Store Listing**에 소개 글과 스크린샷을, **Privacy**에 권한 설명을 채워요.
3. **Submit for Review**를 눌러요.

심사는 보통 며칠 걸리고, 처음 올리는 개발자는 몇 주 걸리기도 해요. 결과는 이메일로 와요.

> [!ok]
> 심사를 통과하면 스토어에 내 확장프로그램 페이지가 생겨요. 그 주소를 친구에게 보내면 **Chrome에 추가** 버튼으로 바로 설치해요.

> [!warn] 거절되면
> 거절 메일 내용을 에이전트에게 붙여 넣고 "Chrome 웹 스토어에서 이렇게 거절됐어, 고쳐 줘"라고 해요. 고친 뒤 새 zip을 올려 다시 제출해요.

> [!route] Chrome 웹 스토어

> [!next] 제출했어요, 다음
