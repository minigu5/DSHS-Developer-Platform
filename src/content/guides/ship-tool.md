## GitHub에 올리고 README 쓰기

도구는 GitHub 저장소 하나와 사용법 설명서(README)만 있으면 친구가 받아서 쓸 수 있어요. 무료예요.

[github.com/signup](https://github.com/signup)에서 가입해요. 가입했으면 에이전트에게 맡겨요.

> [!say]
> 이 프로젝트를 내 GitHub 계정에 공개 저장소로 올려 줘. 그리고 README.md에 이 도구가 뭘 하는지, 설치하는 법, 쓰는 법을 예시와 함께 한국어로 써 줘. 처음 써 보는 친구도 따라 할 수 있게. 로그인이 필요하면 내가 할 수 있게 알려 줘.

중간에 브라우저가 열리면서 GitHub 로그인이나 승인을 물어보면, 그건 내가 눌러 줘요.

> [!ok]
> `github.com/내아이디/저장소이름`에 들어가면 파일 목록 아래에 설치·사용법이 보여요. 친구가 README만 보고 따라 해서 돌아가면 성공이에요.

> [!route] GitHub

## 원하면 npm이나 PyPI에 올리기

여기까지로도 충분해요. 다만 명령 한 줄로 설치하게 하고 싶으면 패키지 저장소에 올려요. Python으로 만들었으면 PyPI, JavaScript로 만들었으면 npm이에요.

> [!say]
> 이 도구를 명령 한 줄로 설치할 수 있게 패키지로 올리고 싶어. 이 프로젝트 언어에 맞는 곳(PyPI나 npm)에 올릴 수 있게 준비해 주고, 내가 가입하고 해야 하는 일을 순서대로 알려 줘. 이름이 이미 쓰이고 있으면 다른 이름을 골라 줘.

> [!ok]
> 친구가 `pip install 내도구` 또는 `npm install -g 내도구` 한 줄로 설치하고 바로 써요.

> [!more] 올리기 전에 알아 둘 것
> - 한 번 올린 버전 번호는 다시 쓸 수 없어요. 고치면 버전을 올려서 다시 올려요.
> - 비밀번호나 API 키 같은 값이 코드에 들어 있지 않은지 에이전트에게 먼저 확인해 달라고 해요. 올리면 누구나 볼 수 있어요.
> - 가입할 때 [pypi.org](https://pypi.org) 또는 [npmjs.com](https://www.npmjs.com)에서 계정을 만들고 이메일 인증을 해요.

> [!route] npm · PyPI
